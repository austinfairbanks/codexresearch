# Research-tool landscape

- Checked: `2026-07-11`
- Scope: capabilities relevant to a source-to-outline research workbench
- Evidence rule: product/project capabilities below are facts supported by the linked official documentation. The “Soleresearch decision” column is a design inference, not a claim made by the cited product.

This is a point-in-time comparison, not a ranking. Product availability, plan limits, models, and interfaces can change. Marketing quality claims are intentionally omitted.

## Boundary decision

Soleresearch should own only the state that makes this workflow accountable:

- question → source → exact passage → interpretation/conclusion/gap → outline traceability;
- agent proposal versus human ratification;
- discussions and promoted takeaways;
- hard run/task/source/agent/depth/time/provider caps and extension reasons;
- human-wins outline reconciliation and visible conflicts;
- portable canonical files, deterministic exports, and rebuildable indexes.

It should integrate or exchange open files with search/research providers, PaperQA2, citation-network discovery tools, and Zotero. It should defer a browser/search engine, broad scholarly index, PDF annotation system, citation-style processor, formal systematic-review protocol, and polished-paper authoring.

## Human-readable presentation rule

The useful review unit is not an agent summary. It is a navigable chain:

`question → source metadata/quality → exact locator + captured passage → proposed meaning → disagreement/gap → accepted graph node → outline location → decision/run event`

The UI and export should retain counterevidence, rejected proposals, curation decisions, and remaining budget beside that chain. A source count or citation link alone does not establish inspection or support.

## Research termination rule

Stop is a controller judgment inside hard caps, informed by coverage, novelty, unread priority sources, contradictions, and explicit gaps. A worker cannot recursively extend itself. Reaching any cycle/task/source/agent/depth/time/provider ceiling pauses the branch; only the active controller may record a bounded extension. This combines the useful bounded-iteration pattern seen in open research agents with a stricter central audit boundary.
